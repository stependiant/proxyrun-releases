# Report a bug

Found a bug or a security issue? [Report a bug](https://github.com/stependiant/proxyrun-releases/issues/new).

Include the Proxyrun version, operating system, steps to reproduce, and the
expected and actual behavior. Remove passwords, tokens, proxy credentials,
packet captures and working exploits before posting: issues are public.

Only published versions explicitly listed as supported receive fixes. The initial
beta has not been independently audited. System capture does not provide a
persistent kill switch; see the user guide for routing limitations.
