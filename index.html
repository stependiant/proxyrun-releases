Windows   /   x64
The upcoming Setup includes the desktop app, CLI and automatic capture-service setup. Run it, approve the service installation and open Proxyrun from Start.

The current beta candidate is unsigned. Coming soon in Releases.

Linux   /   Ubuntu 24.04 · amd64
When the beta is published, download both DEB packages into one folder. For the desktop app and CLI, run:
sudo apt install ./proxyrun_0.1.0-beta.1_amd64.deb ./proxyrun-gui_0.1.0-beta.1_amd64.deb
For CLI only, install just the proxyrun package. APT repository setup will be in the installation guide.
Using WSL?
Use the Linux packages in Ubuntu 24.04 on WSL 2. The desktop interface requires WSLg. These packages route Linux applications; use the Windows installer for Windows apps.
About Auto proxy
Auto proxy can require administrator approval and change system routes and DNS. If system capture stops, apps can use ordinary system routing. There is no persistent system kill switch.
