Your proxy, your choice

Profiles, application launching and Auto proxy are free. No account is required to use your own proxy. Future provider purchases and subscriptions will be optional.

Before you install

Auto proxy can change system routes and DNS and require administrator approval. If system capture stops, applications can use ordinary system routing. There is no persistent system kill switch. WSL packages target Linux applications; use the Windows app for Windows programs.
